# HTML and PHP Practice Website

## Overview

A web-development project stored under the `my-html/` directory. It includes contact pages in HTML and PHP, Bootstrap assets, and related web files. A more detailed README already exists inside that folder; this root README provides an entry point for the repository.

## Mission

Practise building complete web pages and learn how static HTML interfaces can be extended with server-side PHP.

## Goals

- Build and organize clear multi-page website layouts.
- Practise HTML structure, styling, and Bootstrap components.
- Explore PHP-backed form and contact workflows.
- Keep static assets and page files organized.
- Document any database or mail configuration required by dynamic features.

## Repository structure

- `my-html/` — main website practice folder
- `my-html/README.md` — folder-specific project notes
- `my-html/contact.html` — static contact page
- `my-html/contact.php` — PHP contact page
- `my-html/bootstrap-5.3.8-dist/` — Bootstrap distribution files

## Getting started

Open the HTML page in a browser for static review. For PHP pages, run the folder through XAMPP or another PHP-compatible local server.

## Development priorities

Document form handling and any required services, validate user input on the server, and never place private credentials in public source files.
